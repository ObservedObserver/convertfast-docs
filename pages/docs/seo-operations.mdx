# SEO Operations Playbook

This page defines the ongoing checks used to keep `https://ui.convertfa.st` indexable and stable in search.

## Build-Time Checks

Run these commands in CI before deployment:

```bash
yarn build
yarn seo:check
```

`seo:check` fails if it detects:

- wrong canonical host references (`example.com` or `docs.convertfa.st`)
- `noindex` directives in SEO-critical source files
- invalid or missing sitemap/robots host values

## Canonical Rules

- Canonical domain: `https://ui.convertfa.st`
- Redirects:
  - `docs.convertfa.st/*` -> `ui.convertfa.st/*` (301)
  - `www.ui.convertfa.st/*` -> `ui.convertfa.st/*` (301)

## Google Search Console Workflow

After each release, request re-indexing for:

1. `/`
2. `/docs`
3. `/docs/cli`
4. `/blog`
5. Two recently updated blog posts
6. One example page (`/examples/graphic-walker` recommended)

## Weekly Monitoring Checklist

1. Coverage report:
   - track "Crawled - currently not indexed"
   - track "Duplicate, Google chose different canonical"
2. Performance report:
   - check branded query impressions (`convertfast ui`, `convertfast ui cli`)
3. Sitemap status:
   - verify last read timestamp advanced in the past 7 days

## Escalation Triggers

- If indexed pages drop more than 20% week-over-week:
  - freeze content deploys
  - run `yarn seo:check`
  - inspect live `robots.txt` and `sitemap.xml`
  - submit top 10 URLs for inspection in GSC
