# Logo Cloud Section

The Logo Cloud section showcases the logos of your customers or partners.

import { LogoCloud } from '@/components/home/logo-cloud'

<LogoCloud />

To add the Logo Cloud section to your landing page:

```bash
npx convertfast-ui@latest page <your-page> add logo-cloud
```

- **Card**: Sourced from `shadcn-ui`.
