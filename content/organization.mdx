# Publisher and documentation policy

This website documents the ConvertFast UI open-source project. The project maintainer is Observed Observer, using the [ObservedObserver GitHub account](https://github.com/ObservedObserver). ConvertFast UI is the project name; this page does not represent a separately verified company, a customer directory, or a partnership program.

## Verify the source

The [convertfast-ui repository](https://github.com/ObservedObserver/convertfast-ui) contains the CLI and templates. The [convertfast-docs repository](https://github.com/ObservedObserver/convertfast-docs) contains the website source. The npm package is named [convertfast-ui](https://www.npmjs.com/package/convertfast-ui).

When checking an installation instruction, compare the package version with the relevant release and source. The current command documentation covers version 0.2.0. An older article or copied command may describe behavior from an earlier release; the [CLI reference](/docs/cli) is the starting point for current syntax.

## Product facts and examples

Documentation should describe released behavior and state limitations where they affect the workflow. Template content illustrates a layout. Sample testimonials, prices, company logos, and product names are not evidence of customers or endorsements. Historical product-themed example URLs explain design choices and link to current template previews.

Blog articles provide implementation and writing guidance. They do not promise rankings, conversion rates, or revenue. A generated landing page still needs product-specific content, working application behavior, and verification in the environment where it will run.

## Report a correction

Use the relevant repository's issue tracker for a reproducible defect or documentation correction. Link to the page and describe what you expected, what happened, and which command or version you used. A small public reproduction is more useful than a screenshot containing private configuration.

Do not include API keys, access tokens, customer data, or unpublished commercial information in a public issue. The repositories and their issue discussions can be read by anyone. If your report requires private information, remove that information and first describe the problem in general terms.

## Review scope

Technical documentation can change as the CLI evolves. An article's review date records an editorial update, not a guarantee that every external dependency has remained unchanged. Check your application's installed versions and run its own build before deploying generated code.
